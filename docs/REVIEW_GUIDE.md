## 建议现场核验

1. 按 README 登录 demo2，确认联系人、银行卡、余额与验证设置可用。多个评委共用账号时错开付款。
2. 转账草稿中插入查询，再补付款卡，分别核对草稿版本、待验证任务与完成回执。修改金额后核验旧确认不能继续执行。资金结果未知时回读原任务，不能重新创建同款付款来猜测结果。
3. 上传合成账单，核对字段后保存回读；缴费通知仅识别时不得宣称已缴费。
4. 表达偏好并在新对话读取，核对来源与版本；画像须开启用途同意，并独立查询银行事实。
5. 安排坐席使用独立账号在线，补录请求、接收、回复和用户收到回复。demo2 是客户账号，不可当坐席账号使用。

上述为后续核验路线，不是本轮新增通过记录。完整PG、真实模型安全测试、真机语音、并发故障及空环境部署仍需独立记录。
