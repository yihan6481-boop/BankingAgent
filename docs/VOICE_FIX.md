# 语音输入修复 voicefix1

2026-11-02修复后，用户执行线上部署并反馈iPhone Safari与微信内置浏览器均可语音输入。来源、版本及限制见 [VOICE_ACCEPTANCE.md](VOICE_ACCEPTANCE.md)。本次r3只同步说明、模板与材料，运行代码及前端产物保持voicefix1原字节。

## 修改内容

- 点击开始、再次点击结束，另设取消按钮，避免长按操作跨越麦克风授权弹窗。
- 区分识别服务启动与音频采集事件，保留临时结果为需核对的草稿。
- 已配置服务端ASR时，自动通道优先使用MediaRecorder录音转写；浏览器识别保留为可选通道。
- `deploy/server/settings.py`从既有私有模型文件加载明确允许的BA_ASR字段，修复启动时清除语音配置的问题。
- 取消、离页或切换会话阻止迟到回填。文字不自动发送，不直接执行银行业务。
- `deploy/server/voice_check.py`只显示配置状态，不输出密钥，不调用真实供应商。

## 使用方式

登录HTTPS主站，切换语音。点击“点击说话”，允许麦克风，说完点击“点击结束”。转写后检查草稿，再手动发送。可用“取消本次语音”放弃本次录音。自动通道在服务端配置有效时优先走录音转写；权限和录音格式仍受设备限制。

用户反馈Safari及微信可用，不代表所有浏览器与故障场景通过。供应商、鉴权、限制和第三方数据边界见验收记录。部署及配置见 [VOICE_DEPLOY.md](VOICE_DEPLOY.md)，测试命令见 [TESTING.md](TESTING.md)。
